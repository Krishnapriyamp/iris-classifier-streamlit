🌸 Iris Species Predictor

A simple machine learning project that predicts the species of an Iris flower using **scikit-learn** and a **Streamlit web app**.

⚡ Features
- ML model trained on the Iris dataset (classification into setosa, versicolor, virginica)
- Input scaling using StandardScaler
- Interactive UI built with Streamlit
- Probability scores for each prediction
